# Music Visualizer — neon tuner edition

Виртуальный плеер, в котором графика в реальном времени реагирует на музыку. Неоновый стиль тюнингованной машины: кузов-дека с фарами, LED-эквалайзерами по бокам и подсветкой днища, которая пульсирует от баса.

Чистые HTML, CSS и JavaScript — без сборки и библиотек.

## Возможности

**Визуализация**
- **Bars** — зеркальный спектр с пиками и отражением на «мокром асфальте»
- **Wave** — спокойная осциллограмма с привязкой фазы и медленным «эхом»
- **Circle** — неоновое колесо: лучи спектра, вращающиеся спицы, обложка трека в ступице
- **Dash** — приборная панель: громкость (дБ) и темп (BPM) на стрелочных приборах, основной тон (нота и частота), уровни пяти частотных зон
- Плавное «перетекание» между режимами и цветовая волна из центра при смене пресета
- 4 цветовых пресета: Neon Drift, Synthwave, Toxic, Big Rig

**Плеер**
- Локальный плейлист: файлы хранятся в браузере (IndexedDB) и остаются после перезапуска
- Обложки и теги прямо из файлов: MP3 (ID3v2, включая cp1251), FLAC, M4A
- Перемешивание, повтор (весь плейлист / один трек), медиаклавиши клавиатуры
- 5-полосный эквалайзер «как в магнитоле» с пресетами и графиком АЧХ
- Другие источники звука: микрофон и звук вкладки браузера
- Определение темпа (BPM) на лету

**Интерфейс**
- Адаптив для телефона (в том числе горизонтально) и планшета
- Полноэкранный режим с автоскрытием панели

## Запуск

Нужен любой локальный веб-сервер (IndexedDB и захват звука не работают при открытии файла напрямую). Например:

```bash
npx http-server -p 5500 -c-1
```

и открыть `http://localhost:5500`.

Микрофон и звук вкладки браузер разрешает только по `https` или на `localhost`. Звук вкладки работает в Chrome и Edge — в окне выбора нужно включить «Поделиться звуком».

## Управление

| Клавиша | Действие |
| --- | --- |
| `Space` | Play / Pause |
| `N` / `B` | Следующий / предыдущий трек |
| `1`–`4` | Режим визуализации |
| `←` / `→` | Перемотка на 5 секунд |
| `P` | Следующий цветовой пресет |
| `L` | Плейлист |
| `E` | Эквалайзер и настройки |
| `F` | Полноэкранный режим |
| `Esc` | Закрыть панель |

## Как это устроено

```
файл → эквалайзер (5 × BiquadFilter) → лимитер → AnalyserNode → громкость → колонки
микрофон / вкладка ─────────────────────────────→ AnalyserNode
```

Каждый кадр `requestAnimationFrame` приложение забирает спектр и форму волны из `AnalyserNode`, раскладывает спектр на 64 логарифмические полосы и рисует сцену на `<canvas>`. Темп определяется автокорреляцией огибающей «всплесков» спектра за последние 8 секунд.

| Файл | Что внутри |
| --- | --- |
| `index.html` | Разметка: сцена, боковая панель, дека плеера |
| `style.css` | Неоновая тема, пресеты, адаптив |
| `app.js` | Аудиограф, анализ, BPM, режимы Bars / Wave / Circle, плейлист, эквалайзер, источники |
| `scenes.js` | Режим Dash и определение основного тона |
| `tags.js` | Чтение тегов и обложек из MP3, FLAC и M4A |
